# Bundled fonts

These Latin variable WOFF2 subsets are copied from the `@fontsource-variable/inter`
and `@fontsource-variable/jetbrains-mono` 5.3.0 npm distributions. The adjacent OFL
files retain their upstream licenses and copyright notices. They are static app
assets; no font request goes to a CDN at runtime.

Inter uses the standard variable file (weight and optical size). JetBrains Mono
uses the normal variable weight file. Other scripts fall back to the platform
font. The source font projects are https://github.com/rsms/inter and
https://github.com/JetBrains/JetBrainsMono.
